# QuickNotes

QuickNotes is a simple note-taking web app built with HTML, CSS and JavaScript. You can write short notes, give each one a category, search through them and delete the ones you no longer need. Your notes are saved in the browser so they are still there after you refresh the page.

## Features

- Add notes with a category (Personal, Work or Study)
- Validation: empty notes and notes over 200 characters show an error
- Delete any note
- Search notes as you type (not case-sensitive)
- Note counter ("You have no notes yet.", "You have 1 note.", "You have N notes.")
- Notes saved with localStorage
- Responsive layout for small screens

## How to run locally

1. Download or clone this repository.
2. Open the `quicknotes-app` folder.
3. Double-click `index.html` to open it in your browser. No installation is needed.

## What I learned

- Building a page structure with semantic tags like header, main, section and footer.
- Using a Flexbox and a media query to make a layout work on phones.
- Saving and loading data with localStorage, JSON.stringify and JSON.parse.
